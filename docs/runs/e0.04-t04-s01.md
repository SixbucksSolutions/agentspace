## The architect's rulings

Recorded in `docs/decisions.md`, D8 and D21, on `main` in 6bf46da:

- **R1 (A-01, B-01):** the default ProxyCommand is the full path of agentspace's ProxyCommand
  program, found in the folder of the CLI's own executable, then the alias. A `.cmd` or `.bat`
  program runs through `%SystemRoot%\System32\cmd.exe /d /c`. `AGENTSPACE_PROXY_COMMAND` overrides
  it whole. A-02 (how a compiled operator and keeper find the checkout) goes to T05.
- **R2 (A-03, B-02, B-49):** `lease create` MUST NOT depend on the instance-ID cache. The
  ProxyCommand reads it at connect time.
- **R3 (B-03):** each conformance variable names a command that runs that role with the command
  line its spec gives. A one-binary build sets each to a command that selects the role.
- **R4 (B-06):** contract v0's caller is Windows. Linux and macOS callers are later, not blocking.
