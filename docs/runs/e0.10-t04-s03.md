RFC 2119 keywords; the capitals are load-bearing.

The evidence for card #0223 (epic #0050, v0.10, turn T04): every conformance file that `main` holds,
run against the Rust build that `cargo xtask dist` writes, with the deadline case and the
empty-program run; then `cargo test --workspace --locked`, `cargo fmt`, `cargo clippy` and the box's
tests in WSL. It follows
[conformance.md, Running the suite against a build's output folder](../conformance.md#running-the-suite-against-a-builds-output-folder)
and [architect.md, Checking that it still works](../architect.md#checking-that-it-still-works), and its
form is that of [v0.09's whole-suite record](e0.09-t04-s03.md).

**This record is written in two parts, so that writing it stays off the critical path**
(architect.md, the lesson of v0.09-T04). **Part 1 is everything that ran before E0.10-T04-S01 (PR
#159) and E0.10-T04-S02 merged**, all of it on `f4a7945`, the commit every T04 story branched from, by
the dev lead's pin P3 and P55's rule. **Part 2 is what can only run after both merge**: the whole lease
CLI suite and the empty-program run at the final `main`, S02's two operator lanes as adopted by pin
P2, any rerun, and the diff checks. **Each place that part 2 fills is a comment of the form
`<!-- PART2: what goes here -->`, with a visible line after it saying the part is not yet written**,
and it names the run or the check that fills it.
