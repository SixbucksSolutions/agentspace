## The architect's rulings

- **The links to excluded docs stay** (architect, 2026-11-18, before the readers reported). They
  point to records of what happened, not to spec facts, and D34's export rule expects links like
  these. A reader's gap about one is recorded as expected history, and does not count against the
  verdict, unless the reader shows a spec fact that only the excluded doc holds. Neither did.
- **FA-11 and FB-01: the operator carries the repository's own template and `box\system`.**
  - **A first ruling was withdrawn the same evening, before it was written down.** It said the
    rewrite writes its own template and box files from the specs. The dev lead pointed out that it
    contradicted D28 ("The shell that runs on a host (`box/`) stays shell"; not product, so not
    ported) and operator.md. It would also have left the box unbuildable from the package, which
    specifies the box only as the laptop sees it, so FA-11 would have become a blocking gap.
  - **The ruling that stands is D37's addendum.** The template and `box\system` are maintained
    repository files, embedded in the operator at build time as they are. What the prototype
    builds and sends at run time (every ssh remote command line, the patch question, the token
    push's remote script) is the rewrite's own, written from operator.md (D34). D34 gains a line
    saying that its "template's embedded script" means a script the prototype builds at run time.
    operator.md, "What the prototype took from its checkout", states the rule where a builder
    reads it.
