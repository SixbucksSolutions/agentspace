RFC 2119 keywords; the capitals are load-bearing.

The evidence for card #0185 (epic #0048, v0.08, turn T04): every conformance file that `main` held at
the build's commit (the lease CLI, the schemas, the operator and its ProxyCommand, and the keeper), run
against the Rust build that `cargo xtask dist` writes, with the deadline case and the empty-program
run; then `cargo test --workspace --locked`, `cargo fmt` and `cargo clippy`; then the box's tests in
WSL's Ubuntu. It follows
[conformance.md, Running the suite against a build's output folder](../conformance.md#running-the-suite-against-a-builds-output-folder)
and [architect.md, Checking that it still works](../architect.md#checking-that-it-still-works), and its
form is that of [v0.07's whole-suite record](e0.07-t04-s04.md).

- **The run MUST be repeated when the build's code changes**, since a pass belongs to the commit named
  below.
- **This record MUST NOT carry the account ID, the instance ID, a host name, the computer name, the
  Windows user name or a token.** Paths that hold the profile are written `%TEMP%`.
- **The raw output of the run was kept outside the repository**, in `%TEMP%\t04-s04-runs`, one log for
  each conformance file and one output file for each cargo command, and is not committed. Every count
  below was read from the files of the runners, and **every total was summed again by a command over
  those files** (the command is named under each total).
- **A result in this record is a result as found.** The crates' four hung or timed-out targets
  (below, "The crates") are recorded as found under load and as passing when rerun alone. **The
  architect carded them as #0191** (Backlog, related to #0189), and had the workspace run once more
  alone, with nothing else running: that quiet run passed whole (below, "The quiet run").
