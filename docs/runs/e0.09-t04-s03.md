# E0.09-T04-S03 run record: the whole conformance suite and the crates against v0.09's build

RFC 2119 keywords; the capitals are load-bearing.

The evidence for card #0207 (epic #0049, v0.09, turn T04): every conformance file that `main` held,
run against the Rust build that `cargo xtask dist` writes, with the deadline case and the
empty-program run; then `cargo test --workspace --locked`, `cargo fmt` and `cargo clippy`. It follows
[conformance.md, Running the suite against a build's output folder](../conformance.md#running-the-suite-against-a-builds-output-folder)
and [architect.md, Checking that it still works](../architect.md#checking-that-it-still-works), and its
form is that of [v0.08's whole-suite record](e0.08-t04-s04.md).

**This record is in two parts, by the architect's pin P55 (2026-11-24).** The one story still open
when the runs began, #0206 (E0.09-T04-S02), changes only `conformance/operator` files, so the crates
and every non-operator conformance file ran early, on `1a7d33b`; the operator files and the deadline
case run only after #0206 merges, against the final `main`. Part 1, below, holds what ran on `1a7d33b`.
Every place part 2 fills is marked `T04-S03 part 2` in an HTML comment, so a search for that text finds
them all.

- **The run MUST be repeated when the build's code changes**, since a pass belongs to the commit named
  below.
- **P55's rule: the early runs hold only if nothing outside `conformance/operator` differs between
  `1a7d33b` and the final `main`.** `git diff --name-only 1a7d33b <final main>` MUST list only
  `conformance/operator` files (below, "The two commits"). If #0206's review had changed anything
  outside that folder, every early run in this record would be void, and the crates and lane A MUST
  be run again on the final `main`.
- **Each file is counted once, at the commit it ran on.** The crates and the lease CLI, keeper and
  schemas files are counted at `1a7d33b`; the operator files and the deadline case at the final `main`.
  No file is counted at both.
- **This record MUST NOT carry the account ID, the instance ID, a host name, the computer name, the
  Windows user name, a lease ID or alias, or a token.** Paths that hold the profile are written
  `%TEMP%`.
- **The raw output of the runs was kept outside the repository history**, in the `target\runs` folder
  of a detached checkout of `main` at `1a7d33b` (a worktree folder named `v009-t04-runs1`), with one log
  for each conformance file and one output file for each cargo command, and is not committed. Every
  count below was read from those files by a command, and **every total was summed again by a command
  over them**.
- **A result in this record is a result as found.** No file failed and no run was retried, so nothing
  below is a rerun. A failure in these runs would be a finding for the architect to card, never a
  result to retry past.
