## 1. How I would build a drop-in

### The lease CLI (`agentspace.exe`, v0.05)

**Programs:**
- One Rust console program, `agentspace.exe`.
- The POSIX `agentspace` wrapper: `#!/bin/sh`, LF line ends, `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*' exec "<dir>/agentspace.exe" "$@"`.
- For v0.05, a one-line `agentspace-ssh-proxy.cmd` forwarder in both the build folder and the install (operator.md, "Until v0.06 retires the prototype's entry points").

**Modules, in build order:**
1. **args.** The left-to-right tokenizer of lease-api.md "Command lines", with the five-step order for which error is reported. Its tests are table-driven from every example on the page.
2. **values.** Normalizers for the ID, project, platform, profile, size, TTL (short form and ISO 8601) and the state filter. They trim only the exact `White_Space` set, never trim U+FEFF, and match the whole value.
3. **output.**
   - A compact JSON writer: UTF-8, no BOM, one LF.
   - The lease, list and error documents.
   - `\u00xx` escaping of control characters, and the message templates.
4. **schemas.** The eight contract schemas plus `leases.state.schema.json`, embedded (D37). Every printed document and every write is validated against them.
5. **state.**
   - `leases.json`, with the duplicate-ID check and a tolerant read.
   - Atomic replace through `leases.json.<hex>.tmp`, with a 10 s rename retry.
   - `leases.lock` opened share-none, retried for 30 s on sharing violations only.
   - `expired` derived when a record is read, and `driver` read as `ec2` when absent.
6. **ca_check.** The five checks of state.md "Its checks": owner-only DACL by SID, unencrypted key, the first two words exact, and a fingerprint that parses. It never creates a CA.
7. **credential.**
   - An ed25519 key, unencrypted.
   - A user certificate per state.md: key ID is the lease ID, principal `ubuntu`, valid-after back-dated 300 s, valid-before is issue time plus TTL, only the pty and port-forwarding extensions, serial 0.
   - Renewal through `renew-<hex>*` files, keeping the previous certificate until the record is written.
8. **alias.**
   - Inserting the `Include` line: BOM and CRLF handled, backup with a hash check, `ReplaceFile`, refusal on a link or read-only file.
   - The alias file byte for byte.
   - The default ProxyCommand from the executable's own folder (`.exe`, then `.cmd`, a batch file through `cmd.exe /d /c`), written through `<ssh folder>\<alias>.agentspace-tmp-<hex>`.
9. **driver.** An in-process trait with place, renew and release, and one implementation named `ec2` that supports only `linux/arm64`, `agent-linux` and size `m`.
10. **commands.**
    - create: ID draws, full cleanup, leftovers named home-relative.
    - get.
    - renew.
    - release: owner-mark check, then record `released`, then delete the alias, then the folder.
    - list: ordered by `created_at`, then `id`.

**Checked against:**
- `conformance/lease-cli/*` with `AGENTSPACE_CMD` naming the build, and every `test-unmet-*` file passing.
- `conformance/schemas/test-schemas.ps1`.
- One run on a machine whose time zone is not UTC.
- Prototype-to-rewrite interop, both ways.

### The operator (`agentspace-operator.exe` and `agentspace-ssh-proxy.exe`, v0.06)

The operator carries the repository's template, `box\system` and the state schemas as opaque build inputs.

**Modules, in build order:**
1. **cli.**
   - The single-dash parser, the usage-error table and its order.
   - The `-Alias` check: `^[A-Za-z0-9._-]+\z`, no leading `-`.
   - The eight help texts.
2. **proc.**
   - The test seam (`AGENTSPACE_AWS_CMD`, `AGENTSPACE_SSH_CMD`, `AGENTSPACE_SCP_CMD`), with no fallback.
   - Windows OpenSSH by full path, and the AWS CLI by its fixed path, then `PATH`.
   - Every `*_POSIX_FD_STATE` variable stripped, and `AGENTSPACE_NESTED=1` set for children.
   - No stdin to children, and nothing on stdout from `up`.
3. **aws.** The calls of "Calls by command", the JSON members read from each answer, and the #0034 sign-in message.
4. **instance.**
   - The instance-ID cache under `.agentspace\instance-id`.
   - Start-and-wait: the 20-minute launch-time rule, a 15-minute wait polled every 5 s, and the patch question polled up to 20 times.
5. **ca.** Creation (refused when elevated, inside OneDrive or inside a git working tree), the five checks, and the `<problems>` grammar.
6. **push.**
   - The receipt and the `bot.xml` CLIXML structure.
   - `CryptUnprotectData` and the UTF-16LE plaintext.
   - The zone: CLDR `001` mapping, seven legacy names, the zone regex.
   - The stamp, the 20 s clock with a tree kill, the hash-line and zone checks, and the fixed warnings.
7. **commands.** deploy, up, sync (its nine-row call table), down, status and grow, with D36's honest exit codes.
8. **proxy.** It refuses a second argument, prepends to `PATH`, runs `up` in caller mode, and runs the tunnel by its fixed path. The tunnel's stderr is withheld unless `AGENTSPACE_DIAGNOSTIC` is set, and the console mode is repaired.
9. **Box-side remote commands.** Each is written fresh to the spec's "MUST, on the box" steps.

**Checked against:**
- `conformance/operator/*`, with all three `test-unmet-*` files passing.
- The lease CLI suite re-run with the build's `ca`.
- Live `ssh agentspace` and `ssh <lease alias>`.

### The keeper (`agentspace-keeper.exe`, `agentspace-keeper-task.exe`, `agentspace-keeper-install.exe`, v0.06)

**Modules, in build order:**
1. **cli.** The argument table, the six usage checks in order, and exit 2.
2. **log.** An atomic-append writer with five tries, the pass-line grammar, reason sanitizing, and an echo to stdout.
3. **locks.**
   - `board-holder.lock` opened share-none, retried every 100 ms for 10 s.
   - `board-holder-keeper.lock` opened share-read, with the PID written into it.
   - Neither handle is inheritable.
4. **matcher.** The `CommandLineToArgvW` splitter with its quote-run counter, the `cmd /d /c` unwrap, and a self-check at every pass.
5. **pass.** Lock, self-check, rotate the log, read and validate `leases.json` without its lock, trust the record (PID, creation time to the ms, command line), apply the action table including `lost`, and stop a holder's tree leaves first.
6. **launch.**
   - The request file, and WMI `Win32_Process.Create` bounded at 10 s with up to three tries.
   - The claim by `CREATE_NEW`.
   - The launcher's holder start: NUL stdin, one shared append handle, a new process group, breakaway from the job.
   - The result file, withdrawal, the 60 s late wait, the removal order, and the record written before `started` is logged.
7. **watch.** The look, tracking, proof, and backoff or grace (never summed), with the interval floor on every path.
8. **task and install.** The launcher's pass-through and its error log. The installer's usage errors, `-DryRun` output, install-folder refusal, running-keeper refusal, the task fields, and `-Uninstall`.

**Checked against:** `conformance/keeper/test-keeper.ps1` and `test-unmet-holder-dies-mid-pass.ps1` with `AGENTSPACE_KEEPER_CMD`, passing 5 times in a row beside two other copies of the suite.
