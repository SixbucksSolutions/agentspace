The evidence for card #0207 (epic #0049, v0.09, turn T04): every conformance file that `main` held,
run against the Rust build that `cargo xtask dist` writes, with the deadline case and the
empty-program run; then `cargo test --workspace --locked`, `cargo fmt` and `cargo clippy`. It follows

**This record is in two parts, by the architect's pin P55 (2026-11-24).** The one story still open
when the runs began, #0206 (E0.09-T04-S02), changes only `conformance/operator` files, so the crates
and every non-operator conformance file ran early, on `1a7d33b`; the operator files and the deadline
case run only after #0206 merges, against the final `main`. Part 1 holds what ran on `1a7d33b`. Part 2
holds the operator files and the deadline case, which ran on the final `main`, `df5aa9c`, and the one
operator file that P56 (2026-11-24) fixed and ran again on `0691ed5`, a commit of this story's branch.

  below.

  `conformance/operator` differs between `1a7d33b` and the final `main`.** P55 allows
  `docs/operator.md` beside the operator files. `git diff --name-only 1a7d33b <final main>` MUST list

  schemas files are counted at `1a7d33b`; the operator files and the deadline case at the final `main`,
  except `test-unmet-host-alias-file.ps1`, which is counted by its green run at `0691ed5` (pin P56,

- **This record MUST NOT carry the account ID, the instance ID, a host name, the computer name, the

- **The raw output of the runs was kept outside the repository history**, in the `target\runs` folder
